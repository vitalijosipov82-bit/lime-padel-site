# ЛАЙМ / Казань — PLAN.md

**Задача для Codex:** разработать главную страницу падел-клуба из пяти секций. Посетитель с первого экрана понимает, где находится клуб, и может сразу перейти к записи. Если он ещё выбирает, страница помогает подготовиться к первому визиту, сравнить форматы и цены, увидеть клуб и найти вход.

**Режиссура:** «розыгрыш в пяти кадрах». Линии реального корта становятся графическим мотивом: резкая подача в Hero, точная смена позиции во вкладках, тактическая схема у тарифов, три плана в одной рамке и линия пути в финале. Самая длинная сцена только одна. Сайт должен выглядеть собранным и выразительным даже на статичном кадре.

## 0. Контракт реализации

- **Источники.** `DESIGN.md` задаёт сетку, типографику, темы, состояния и правила движения; `CONTENT.md` — инвентаризация старого сайта и источник для сверки. Записи аудита не равны подтверждённым данным. Указанные здесь композиции, селекторы и файлы — проектная схема. Если новое движение или компонент выходит за `DESIGN.md`, сначала согласовать и добавить его в дизайн-систему. Примеры из запроса — направление для выразительности: горизонтальный перехват скролла, закрепление тренеров и плавающий курсор в этой версии не реализуем.
- **Старт проекта.** На момент подготовки плана `index.html`, `style.css` и `script.js.js` пустые; в `images/` есть каталоги `Интерьер`, `Модель`, `Тренеры`, `logo`. Перед кодом проверить состояние репозитория, просмотреть кадры и составить список утверждённых файлов, сюжетов, `alt`, точек кадрирования и прав на публикацию. Названия каталогов сами по себе ничего не доказывают о содержимом кадров. Пустой `script.js.js` не подключать; если файл уже изменён, сначала разобраться, что в нём используется.
- **Стек.** HTML5, CSS Custom Properties, CSS Grid и Flexbox, Vanilla JS ES modules, GSAP 3 + ScrollTrigger, Lenis 1.3. npm + Vite для локальной разработки и сборки статического `dist/`, без SPA, UI-библиотек, CDN-дублей и клиентского рендера основного контента. Зафиксировать точные версии и закоммитить lock-файл. Проверка сборки: `npm ci` → `npm run build` → открыть сборку через `npm run preview`.
- **Структура.** `index.html` хранит смысловой HTML, тарифы и ссылки. `style.css` — токены, сетка и стили секций. `src/main.js` подключает `src/scroll.js`, `src/ui/{theme,menu,visit-tabs}.js` и `src/motion/{hero,entry,club}.js`; `entry.js` обслуживает декоративные входы секций 03 и 05. Модули инициализируются независимо и возвращают функции очистки; падение эффекта не должно отключать навигацию или запись. `public/media/` — подготовленные медиа, `public/fonts/` — локальные Oswald и Manrope WOFF2 с кириллицей и латиницей, `font-display: swap`.
- **Семантика.** `lang="ru"`, ссылка «К основному содержимому», `header`, `main#main` с пятью верхнеуровневыми `<section>` в порядке ниже, `footer`. Один H1, H2 для каждой из оставшихся секций, H3 для вложенных блоков. Шапка содержит логотип, якоря на секции 02–05, переключатель темы и ссылку «Забронировать корт». Мобильное меню — нативный `<dialog>` с фокусом внутри, Escape, возвратом фокуса и блокировкой фонового скролла; GSAP использует фазы меню из `DESIGN.md §4`. Юридические ссылки находятся в футере и не образуют шестую секцию.
- **Сетка и слои.** Применить `DESIGN.md §2–3, §5`: 12/8/4 колонки, поля 48/32/20 px, межколонник 24/20/16 px, вертикальный отступ секций 112/80/56 px, максимум контента 1440 px. На десктопе Hero H1 — 96/100 px, на планшете — 68/74 px, на мобильном — 44/48 px; в CSS размеры в `rem`, межстрочный интервал без единиц. Тёмные токены принудительно в 01 и 04, на остальных — системная тема с сохранённым ручным выбором до первого отображения. В сценах использовать локальный `isolation: isolate`: медиа → декор → читаемый контент; декор `pointer-events: none`, диалог в top layer. Фокус `2px` с `outline-offset: 3px`, цели от 44 × 44 px, основной CTA от 48 px. На секцию не более одного основного CTA. Заливку и стрелку CTA анимировать по `DESIGN.md §4`, hover только при точном указателе.
- **Медиа.** Использовать фотографии клуба и людей с разрешением на публикацию. `<picture>` с AVIF/WebP и резервным форматом, `srcset`/`sizes`, заданные размеры или `aspect-ratio`. Hero-постер грузить сразу с `fetchpriority="high"`; остальные изображения вне видимой зоны — отложенно. Не ждать загрузки всей галереи, чтобы показать Hero. Геометрия рамок не зависит от декодирования фото. Декоративные линии рисовать CSS или встроенным SVG, без фильтров на весь экран.

### Контракт GSAP и скролла

1. Один `gsap.registerPlugin(ScrollTrigger)`. Настройки через `gsap.matchMedia()`: `motion = '(prefers-reduced-motion: no-preference)'`; `smooth = '(min-width: 1024px) and (pointer: fine) and (hover: hover) and (prefers-reduced-motion: no-preference)'`; `pin = '(min-width: 1200px) and (min-height: 760px) and (pointer: fine) and (hover: hover) and (prefers-reduced-motion: no-preference)'`. Нативный оконный скролл во всех режимах без Lenis. Без `scrollerProxy`, scroll hijack и глобального `snap`.
2. В `smooth` создать один Lenis: `{ autoRaf: false, smoothWheel: true, syncTouch: false, lerp: 0.12, wheelMultiplier: 1, infinite: false, anchors: true }`. Подключить CSS Lenis, `lenis.on('scroll', ScrollTrigger.update)`, `gsap.ticker.add(tick)` с `tick = t => lenis.raf(t * 1000)`, `gsap.ticker.lagSmoothing(0)`. `scroll-behavior: auto`; якорный отступ = текущая высота шапки + 16 px, учесть его один раз и для нативного перехода, и для Lenis. При открытом меню остановить Lenis и заблокировать прокрутку фона; внутри диалога оставить нативную прокрутку, после закрытия восстановить позицию.
3. Привязать эффекты к локальным контекстам. Обработчики, создающие анимации позже, тоже регистрировать в контексте либо явно уничтожать их твины при очистке. При смене режима убрать GSAP-стили, триггеры, spacer закрепления, DOM-классы, обработчики, наблюдатели и старый `tick`; вызвать `lenis.destroy()`. Hero не проигрывается заново при смене режима. После готовности шрифтов и реальных изменений размеров выполнить объединённый `ScrollTrigger.refresh()` вне кадрового цикла. Не обновлять геометрию на каждом скролле. Регистрировать сцены в порядке DOM и проверить пересчёт триггеров ниже закрепления.
4. База без JS — весь текст, контакты, тарифы, формы навигации и ссылки читаемы; вкладки представлены тремя блоками, галерея — обычным потоком. Скрытые стартовые стили ставит только успешно запущенный модуль. В `reduce` нет Lenis, закрепления и плавных переходов; кнопки и вкладки меняют состояние сразу. Обычный курсор, без прелоадера, bounce и параллакса текста. Контраст проверять поверх финальных кадров: текст ≥ 4,5:1, значимые границы и фокус ≥ 3:1.

Официальная справка для реализации: [ScrollTrigger](https://gsap.com/docs/v3/Plugins/ScrollTrigger/), [gsap.matchMedia()](https://gsap.com/docs/v3/GSAP/gsap.matchMedia%28%29/), [Lenis + ScrollTrigger](https://github.com/darkroomengineering/lenis#gsap-scrolltrigger).

## 01. `#hero` — «Подача»

**Композиция и эффект.** Две строки H1: «ПАДЕЛ-КЛУБ / ЛАЙМ». На 12 колонках текст занимает 1–6, фото корта доминирует в 7–12; факт локации закреплён композиционно в правом нижнем углу кадра. Выбрать реальный ракурс, где белая линия корта уходит к правому краю. Продлить её коротким декоративным штрихом внутри слоя медиа: маска одним движением открывает фотографию и линию, следом встаёт заголовок. На планшете — 4 + 4 колонки; на телефоне — шапка, H1, лид, CTA, затем медиа. За текстом на фото подложка `#101A17` непрозрачностью минимум 72%, контраст проверить по фактическому кадру.

**GSAP.** Один `gsap.timeline({ defaults: { ease: 'power3.out', overwrite: 'auto' } })`. В `0.00` — рамка медиа `clipPath: 'inset(0 8% 0 0)'` → `'inset(0%)'`, `duration: 0.64`. В `0.10` — H1 целиком `y: 18, opacity: 0` → `y: 0, opacity: 1`, `duration: 0.50`, `stagger: 0`. Без `ScrollTrigger`, `pin`, `scrub` и дробления заголовка на символы. Лид, локация и ссылка видны сразу. При прямом якоре, возврате с восстановленной позицией или `reduce` показывать конечный кадр. Первая версия — постер; если утверждено авто-видео, нужен видимый переключатель паузы и постер при отказе или `reduce`.

**Данные из `CONTENT.md`.** §2 «Заголовки…» и «Позиционирование»: быстрый вход в игру, азарт, игра с друзьями; взять этот смысл в один лид, например «Играйте с друзьями или начните с тренером». §2 «Контактные данные»: название «Лайм», Казань, ТЦ «Франт»; короткая подпись «Казань · ТЦ „Франт“», полный адрес — в 05. §3 «Онлайн-запись»: реальная ссылка YCLIENTS после сверки (см. 03), подпись по дизайн-системе «Забронировать корт».

**Готово, когда:** при 360 × 640 px CTA целиком на первом экране в масштабе 100%; при 200% заголовок переносится, блок растёт. При блокировке GSAP видны фото, заголовок, локация и кнопка. Нажатие доступно во время вступительной анимации.

## 02. `#first-visit` — «Табло первого визита»

**Композиция и эффект.** Три вкладки «Забронировать», «Найти партнёра», «Что взять». Текст слева, действие рядом, под ними широкая рамка фото: `16:9` на десктопе, `4:3` на телефоне. Метка под активной вкладкой переезжает по общей базовой линии, как отметка на табло; новый кадр накладывается на старый внутри рамки без сдвига интерфейса. Содержимое панели меняется сразу. Общий короткий вводный текст о паделе виден при любой вкладке.

**GSAP.** Декоративный штрих: измерить `x` и ширину вкладки относительно полосы; позицию и ширину штриха менять через `x` и `scaleX` при `transformOrigin: 'left center'`. `gsap.to(indicator, { x, scaleX, duration: 0.22, ease: 'power2.out', overwrite: 'auto' })`. Цвет и линия 2 px под активной вкладкой меняются сразу, поверх них проходит короткий акцентный штрих; в конце твина скрыть штрих, чтобы не было двойной полосы. При изменении размера пересчитать измерения. Два слоя фото: после `img.decode()` новый поверх старого, `opacity: 0 → 1`, `duration: 0.32`, `ease: 'power2.out'`. Хранить номер последнего выбора; устаревшие результаты декодирования игнорировать, текущую анимацию фото завершать или заменять, при ошибке брать утверждённый постер вкладки. Размер рамки сохраняется. `ScrollTrigger`, `pin`, `scrub` отсутствуют, `stagger: 0`.

**HTML и управление.** Базовые три блока с заголовками, ссылками и своими фото; роли `tablist`, `tab`, `tabpanel`, `aria-selected`, `aria-controls` и roving `tabindex` назначать только после успешной инициализации. Стрелки и Home/End перемещают фокус, Enter/Space активируют вкладку, Tab уводит в выбранную панель. Не перемещать фокус из вкладки при смене фото. «Забронировать» ведёт к `#booking`; Telegram — вторичная текстовая ссылка. В `reduce` штрих и фото обновляются без твинов.

**Данные из `CONTENT.md`.** §2 «Позиционирование» и дополнительный текст об игре: обычный формат 2 × 2, игра со стенами и отскоками, короткая ракетка, мягкий мяч, вход для новичков. Описать правила через эти признаки; старое сравнение с пляжным волейболом не переносить как определение. «Забронировать» — сравнить аренду и занятия, перейти к тарифам (§2–3). «Найти партнёра» — знакомство, поиск команды и [Telegram клуба](https://t.me/lime_padel) (§1–2). «Что взять» — прокат любительских и профессиональных ракеток, мячи включены в аренду корта после подтверждения (§2 «Тарифы»). Одежду, обувь, душевые и раздевалки не обещать без ответа клуба (§5).

**Готово, когда:** текст меняется до загрузки фото, из пяти быстрых переключений побеждает последнее; высота рамки сохраняется. Навигация работает с клавиатуры и тачем. Без JS доступны все три шага и их действия.

## 03. `#booking` — «Тактическая доска»

**Композиция и эффект.** Тарифы похожи на разметку матча: четыре открытых блока с табличными цифрами `font-variant-numeric: tabular-nums`, ясными единицами и разными уровнями заголовков. «Аренда корта» занимает главный пролёт, индивидуальные и групповые занятия идут рядом или ниже по сетке, прокат завершает сравнение. На мобильном — последовательно в одну колонку. За заголовком — три крупные отдельные плоскости декоративной схемы корта: контур, центральная линия, зона подачи. Они собираются в цельную схему в начале секции; цена и кнопка не участвуют в анимации. Под тарифами — одна основная ссылка «Забронировать корт» и рядом телефон на случай сбоя.

## 04. `#inside` — «Три кадра одного матча»

**Композиция и эффект.** На тёмном фоне один широкий неподвижный экран: общий план корта → средний план игры → люди после матча. Рамка остаётся на месте, новый кадр входит снизу, как сдвиг панели на площадке. Внутри закреплённой области только рамка и подпись; H2 «Внутри клуба» и ссылка «Пропустить галерею» перед сценой, команда и сообщество после неё в обычном потоке. Верхний внутренний отступ сцены учитывает высоту шапки, рамка подстраивается по высоте окна. Если при увеличении текста кадр и подпись не помещаются, включить обычный поток. Ссылка пропуска ведёт к `#coaches`; после перехода фокус на его заголовке.

**ScrollTrigger.** Единственный pin на сайте. Инициализировать при совпадении `pin` из §0 и готовности всех трёх утверждённых кадров; размеры рамки должны быть известны до активации. Триггер и pin — внешний блочный `.club-scene`; анимировать только внутренние слои. Без `transform`, `will-change: transform` и `overflow: hidden` на предках pin; обрезка только у внутренней рамки. Блочный родитель оставляет место для spacer. Конфигурация:

```js
{ trigger: scene, start: 'top top', end: '+=140%', pin: true,
  pinSpacing: true, scrub: true, snap: false, invalidateOnRefresh: true }
```

Таймлайн `0…1` с тремя слоями в DOM: A снизу, B поверх A, C поверх B. Для B и C задать `yPercent: 100` до движения; у всех одинаковая геометрия. Родитель кадрирует движение через `overflow: hidden`. На `0.24` запустить B `yPercent: 100 → 0`, на `0.66` запустить C так же; оба `duration: 0.10` единицы таймлайна, `delay: 0`, `ease: 'none'`, `stagger: 0`. Не менять время таймлайна через сетевой ответ. Чтобы полная длительность была ровно `1`, добавить служебный tween нейтрального JS-объекта `duration: 1, ease: 'none'` от `0`; он не меняет DOM. Подпись вычислять из прогресса таймлайна по порогам `0.29` и `0.71`; менять только при смене индекса, в обе стороны, без `aria-live`.

1. **Инвентаризация.** Сверить файлы и медиа, выписать открытые вопросы к клубу: цены и единицы, типы кортов, адрес и вход, каналы связи, профили, права на фото и поведение YCLIENTS. Данные, которые не подтвердили, не блокируют вёрстку, но не попадают в публичные обещания.
